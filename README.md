# Neon HUD Keyboard v2 (Android 11+ / Redmi Note 13 5G, Android 15)

## APK बनाना
1. पूरा फ़ोल्डर GitHub repo में upload करें (.github समेत)।
2. Actions -> Build APK -> Artifacts से APK लें।

## उंगली के इफ़ेक्ट के लिए (एक बार का सेटअप)
1. Play Store से **Shizuku** इंस्टॉल करें।
2. Settings > About phone > MIUI/HyperOS version पर 7 बार टैप करके Developer options चालू करें।
3. Developer options > **Wireless debugging** चालू करें (WiFi पर)।
4. Shizuku खोलें > "Pairing" के ज़रिए pair करें > **Start** दबाएँ। (फ़ोन restart के बाद दोबारा Start करना पड़ता है।)
5. Neon HUD ऐप में: बटन 3 (Accessibility चालू), फिर बटन 4 (Shizuku अनुमति)।
6. Battery > Neon HUD > "No restrictions" और Autostart चालू रखें।

Accessibility बटन ग्रे हो तो: Settings > Apps > Neon HUD > ⋮ > Allow restricted settings।
